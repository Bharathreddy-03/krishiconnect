# 🌾 KrishiConnect  
### A Simple Digital Bridge Between Farmers & Agricultural Labourers

KrishiConnect is a user-friendly web application designed to connect **farmers needing labour** and **agricultural labourers seeking work**.  
The platform allows **profile creation, job posting, searching, applications, notifications, and chatting** — all using a simple front-end system.

---

## 🚀 Features

### 👨‍🌾 Farmer Features
- Create & manage farmer profile  
- Post work requirements (type, date, location, workers needed)  
- View applications from labourers  
- Chat directly with applicants  

### 👷‍♂ Labourer Features
- Create labour profile  
- Search for work by city/village  
- View available farmer vacancies  
- Apply to vacancies  
- Chat with farmers  

### 💬 Chat System
- Browser-based chat saved in localStorage  
- Unique chat per farmer–labourer pair  

### 🧩 General Features
- Clean and colourful UI  
- Fully responsive  
- 100% front-end (no backend required)

## 🛠 Technologies Used
- **HTML5** – Page structure  
- **CSS3** – UI/UX styling, animations  
- **JavaScript (ES6)** – App logic  
- **LocalStorage** – Data persistence without backend  

## ▶️ How to Run the Project
1. Download or clone the project folder  
2. Open in **VS Code**  
3. Right-click `index.html` → **Open with Live Server**  
4. Start using the application  

> No backend, database, or frameworks required.
